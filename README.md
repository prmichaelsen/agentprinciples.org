# agentprinciples.org

> A public principles commons + conformance registry for AI agent
> systems. Principles are published as numbered, citable RFCs;
> conformance is declared by signed attestations against those
> RFCs.

Both human readers and agent consumers are first-class. The read
surface ships HTML, JSON, RSS, and an MCP endpoint from day zero.
RFCs are versioned, stably URI'd, and amend/supersede each other
through an append-only chain.

Status: bootstrap. First RFCs forthcoming.

Stack: TanStack Router + TanStack Query + SSR on Cloudflare
(Pages, Workers, D1, Browser Rendering).
